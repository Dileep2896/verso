Drop a PDF to check it
Verso reads what a parser sees vs. what a person sees — locally. Nothing is uploaded.

How it works

1
You drop in a PDF. Nothing is uploaded to the cloud — it's checked right here.
2
Verso compares what a parser reads against what a person sees, plus the file's hidden data. This is a fixed set of rules — no AI decides.
3
You get a plain verdict and the document with every hidden item marked, page by page.

What counts as hidden

Invisible text — written in the file, painted invisibly on the page
Off-page text — positioned outside the visible page
Text under a box — a redaction with the words still underneath
Microscopic text — too small for a person to read
Hidden code & data — embedded scripts, files, and metadata
